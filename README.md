# AI Email Responder (n8n + Claude)

An n8n workflow that reads incoming Gmail emails and writes smart replies using Claude.

## What it does
- Watches Gmail for new emails
- Sends the email to Claude
- Creates a reply draft automatically

## How to use
1. Download the workflow .json file
2. In n8n: Workflows > Import from file
3. Connect your own Gmail and Claude credentials
4. Activate the workflow
